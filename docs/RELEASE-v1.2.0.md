# Graphite Rounded v1.2.0

基于 Graphite 石墨皮肤的圆角与深色适配版本。

**原设计作者：** [xiaochunjimmy](https://github.com/xiaochunjimmy)（Jimmy Cheung / Remix Design）  
**Windows 移植作者：** [jrfeng](https://github.com/jrfeng)  
**上游项目：** [Remix-Design/Sogou-Input-Skin](https://github.com/Remix-Design/Sogou-Input-Skin)

## 本次改动

- 浅色 / 深色两套 8px 圆角、1px 边框与柔和阴影。
- 修正横排、竖排和分窗口切片，保留字号、间距与原作者字段。
- 提供搜狗 Windows 16.6.0.4777 经典默认槽位接入包、手动安装和完整还原脚本。
- 附普通单主题 `.ssf`，便于独立使用。

## 下载选择

- `Graphite-Rounded-Native-LightDark-16.6.zip`：完整原生浅深模式接入包，先阅读说明，安装会替换经典默认槽位的两个资源文件。
- `Graphite-Rounded-Light.ssf` / `Graphite-Rounded-Dark.ssf`：普通单主题皮肤，各文件只有一种配色。
- `preview.png`：两套配色与圆角示意，非运行截图。

已通过 120 组圆角拉伸检查、资源/包校验和 10 项安装还原副本测试。原生接入包的实际输入候选窗与不同 DPI 兼容性仍需使用者验证。

原皮肤设计与移植署名归原作者，本发布仅包含二次改动，不代表原作者背书。
