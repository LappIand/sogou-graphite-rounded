# 验证范围

## 已完成

- 原作者字段 `skin_author=jrfeng` 与上游来源保留。
- 浅色、深色各 49 个包成员和 48 个图像资源引用。
- 六张背景的 8px 圆角、1px 边框、2.3px 模糊和 2px 下移阴影。
- 两套共 120 组宽高拉伸检查，四个固定角区域逐字节保持不变。
- 原字体、字号、候选间距、按钮位置和所有非背景图标不变。
- UTF-16LE BOM、原配置 CRLF、ZIP CRC 和 `.dat`/`.ssf` 成员相等检查。
- 安装还原工具的 10 项工作目录副本测试：检查、备份安装、重复安装、还原、源文件损坏、版本不匹配、非管理员、写入失败回滚、清单目标路径篡改、损坏源/缺失目标时还原。

资源检查可通过 `python scripts/build.py` 重跑；打包与公开清单检查可通过 `python scripts/package.py` 重跑。制作时的资源与安装副本测试报告分别为 `resource-validation.json`、`installer-validation.json`。
